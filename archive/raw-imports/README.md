# Raw Import / Recovery Reference

This path is a bounded recovery/reference location only. It must not become a duplicate canonical archive or a reason to copy current Drive/Type-1/Git sources unnecessarily.

For any legacy script/export/source under review:

1. identify the exact original source and current canonical owner;
2. extract and reconcile unique content first;
3. use a stable source pointer/checksum instead of copying the object when possible;
4. retain a recovery copy only where required by provenance or rollback policy;
5. archive/delete only after canonical destination/readback and recovery gates close.

Historical presence here never promotes an object to current authority.
